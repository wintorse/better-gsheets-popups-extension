# Better GSheets Popups Extension

Google スプレッドシートのコメントポップアップ、セルの編集履歴ポップアップを見やすくする Chrome 拡張機能

## 機能

コメントポップアップ関連
- **コメントポップアップの横幅拡張**: コメントポップアップをビューポート幅の 32% に拡大します（最小 240px）
- **コメントポップアップのサイズ変更**: コメントポップアップのサイズを自由に変更できるようにします
- **はみ出し防止**: コメントポップアップが画面右端を超えた場合、自動で `left` 位置を補正します
- **iframe 対応**: Google スプレッドシート内の iframe にもスタイルを注入します
- **動的コンテンツ対応**: MutationObserver を使用し、後から追加されるコメントポップアップにも自動で適用します

セルの編集履歴ポップアップ関連
- **編集履歴ポップアップのサイズ変更**: 編集履歴ポップアップのサイズを自由に変更できるようにします
- **編集履歴ポップアップのdiff表示**: 編集履歴ポップアップで変更内容の差分をgit diff風に表示します

## インストール

1. このリポジトリをクローンまたはダウンロードします
2. Chrome で `chrome://extensions` を開きます
3. 右上の「デベロッパーモード」を有効にします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリのフォルダを選択します

## 対応 URL

`https://docs.google.com/spreadsheets/*`
