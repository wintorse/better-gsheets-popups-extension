# Better GSheets Popups Extension

Google スプレッドシートのコメント、セルの編集履歴を見やすくする Chrome 拡張機能

## 機能

コメントポップアップ関連
- **初期幅のカスタマイズ**: 拡張機能アイコンのポップアップから、コメントを開いたときのデフォルトの幅を変更できます
- **コメントの横幅拡張**: 右下のハンドルでコメントの横幅を変更できます
- **はみ出し防止**: コメントポップアップが画面左右の端を超えた場合、自動で位置と幅を補正します
- **iframe 対応**: Google スプレッドシート内の同一 origin iframe にもスタイルと監視処理を適用します
- **動的コンテンツ対応**: MutationObserver を使用し、後から追加・更新されるコメントポップアップにも自動で適用します

セルの編集履歴ポップアップ関連
- **初期幅のカスタマイズ**: 拡張機能アイコンのポップアップから、編集履歴を開いたときのデフォルトの幅を変更できます
- **編集履歴のリサイズ**: 右下のハンドルで編集履歴の幅と本文領域の高さを変更できます
- **編集履歴のはみ出し防止**: 編集履歴表示が画面左右・下端を超えた場合、自動で位置と幅を補正します
- **編集履歴の diff 表示**: 追加・削除・置換されたセル値を git diff 風に表示します
- **単語単位の差分強調**: 置換履歴では変更前後の差分を単語単位で強調します
- **diff レイアウト切替**: diff 表示を縦並び・横並びで切り替えられます

## インストール

1. このリポジトリをクローンまたはダウンロードします
2. Chrome で `chrome://extensions` を開きます
3. 右上の「デベロッパーモード」を有効にします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このリポジトリのフォルダを選択します

## 対応 URL

`https://docs.google.com/spreadsheets/*`
